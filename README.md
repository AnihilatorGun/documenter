# Documenter

Домашний трекер документов на семью. Сканы паспортов, виз, страховок и справок
лежат в вашем Google Диске, а приложение позволяет искать их по человеку, тегу,
языку и — главное — показывает, что скоро истекает.

Работает на вашем компьютере и открывается в браузере. Никакого сервера в интернете,
никакой регистрации: всё хранится в вашем же Google Диске.

## Что умеет

* Карточка документа с несколькими файлами: лицевая и оборотная сторона,
  оригинал и перевод, PDF и фотография — всё в одном месте.
* Фильтры по человеку, тегу (виза, медицина, ИП, учёба, налоги, легализация)
  и языку, плюс поиск по названию и заметкам.
* Срок действия с предупреждением: что уже просрочено и что истекает в ближайшее время.
* Общее хранилище на семью — у каждого своё приложение, документы одни и те же.

## Установка

### 1. Скачать

На странице проекта в GitHub нажать зелёную кнопку **Code** → **Download ZIP**,
распаковать архив в удобное место (например в «Документы»). Папку потом лучше
не переносить — ярлык запуска работает из той папки, где лежит.

### 2. Установить

Дважды кликнуть по файлу:

* **macOS** — `Install.command`
* **Windows** — `Install.bat`

Откроется чёрное окно, установка займёт минуту-две. Когда там появится «Готово»,
окно можно закрыть.

> **Если macOS ругается «неизвестный разработчик»** — нажать на файл правой кнопкой
> и выбрать «Открыть», затем подтвердить. Так система разрешает запуск файлов,
> скачанных из интернета. Второй раз спрашивать не будет.

### 3. Запустить

Дважды кликнуть по `Documenter.command` (macOS) или `Documenter.bat` (Windows).
Приложение запустится и само откроет браузер. Чтобы выключить — закрыть окно,
которое при этом появилось.

Дальше: если приложение ставит **владелец документов** — переходите к разделу
«Доступ к Google Диску». Если вас **подключают к уже готовым документам** — вам
должны прислать приглашение и ключ, см. «Как подключить второго человека».

## Доступ к Google Диску

Этот раздел нужен один раз и только владельцу — тому, в чьём Диске будут лежать
документы. Остальные члены семьи подключаются приглашением и ничего этого не делают.

1. Зайти в [Google Cloud Console](https://console.cloud.google.com/) и создать проект.
2. Включить **Google Drive API**.
3. Открыть **APIs & Services → Google Auth Platform** (раньше этот раздел назывался
   OAuth consent screen, Google его переименовал). Если заходите впервые — «Get started»:
   название приложения, почта для поддержки, **Audience = External**.
4. Там же на вкладке **Audience** нажать **Publish app**, чтобы статус стал
   `In production`. Это важно: в статусе Testing Google отзывает выданный доступ
   каждые 7 дней, и приложение будет терять связь с Диском раз в неделю. Проверка
   от Google при этом не нужна — приложение видит только те файлы, которые само
   создало, а такой доступ не считается чувствительным.
5. На вкладке **Clients** создать client типа Web application и в Authorized
   redirect URIs добавить `http://localhost:8000/auth/callback`. Вкладку Data access
   трогать не нужно.
6. Скопировать файл `.env.example` в `.env` и заполнить: client id, client secret,
   свою почту в `OWNER_EMAIL`, почты остальных членов семьи в `ALLOWED_EMAILS`,
   любую случайную строку в `SESSION_SECRET`, и написать `STORAGE=drive`.

После этого запустить приложение и войти своей почтой. **На экране согласия Google
доступ к Диску идёт отдельной галочкой, и по умолчанию она снята — её нужно
отметить**, иначе класть документы будет некуда. Приложение это проверяет и не
пустит владельца без неё.

Про пункт «Audience = External», который выглядит пугающе: он означает «окно входа
Google может увидеть любой гугл-аккаунт», а не «любой видит ваши документы». Внутрь
пускает не Google, а само приложение — оно сверяет почту со списком в `.env` и
отказывает всем остальным. Вариант Internal доступен только владельцам корпоративного
домена в Google Workspace, у обычной почты выбора просто нет.

## Как пользоваться

Документ — это карточка, а не файл. У одной карточки может быть несколько файлов.

| Поле | Обязательное | Зачем |
|---|---|---|
| Название | да | «Карта побыту Никиты» |
| Личности | нет | чьи это документы; их может быть несколько |
| Теги | нет | виза, медицина, ИП, учёба, налоги, легализация; можно добавлять свои |
| Языки | нет | русский, польский, английский |
| Номер | нет | номер документа, чтобы не лезть в скан ради анкеты |
| Кем выдан | нет | орган или страна выдачи |
| Дата выдачи | нет | |
| Действует до | нет | из этого поля растёт предупреждение «истекает скоро» |
| Заметки | нет | свободный текст, участвует в поиске |

Фильтры на главной странице комбинируются так: внутри одной группы — ИЛИ (выбрали
двух человек — увидите документы любого из них), между группами — И (человек И тег).

## Как подключить второго человека

У него на компьютере поднимается такая же копия приложения. Общий у них только
Google Диск. Переносить файлы руками не нужно — для этого есть приглашение.

1. **Владелец:** добавить почту этого человека в `ALLOWED_EMAILS` в файле `.env`
   и перезапустить приложение, иначе войти он не сможет.
2. **Владелец:** пункт «Приглашение» в шапке → «Создать приглашение». Появятся
   две строки: само приглашение и ключ к нему.
3. Отправить их **разными способами**: например приглашение в мессенджере, а ключ
   голосом или из рук в руки. Если оба уйдут в одну переписку, шифрование не защитит
   ни от чего — тому, кто прочитает переписку, достанется и то, и другое.
4. **Второй человек:** установить приложение (см. «Установка»), запустить, на первом
   экране выбрать «У меня есть приглашение» и вставить обе строки.
5. Перезапустить приложение. При старте оно скачает документы семьи из Диска.

После этого второй компьютер полноценный: видит все документы, фильтры и сроки,
может добавлять свои. Если владелец отзовёт доступ приложения в настройках своего
Google-аккаунта, перестанут работать обе копии — это один и тот же доступ.

## Если что-то пошло не так

**«Неизвестный разработчик» при двойном клике (macOS).** Нажать на файл правой
кнопкой → «Открыть» → подтвердить.

**«Address already in use» или «порт занят».** Приложение уже запущено в другом
окне — найдите его и закройте. Если окна не видно, на macOS помогает команда
в Терминале: `kill -9 $(lsof -t -i:8000)`.

**Приложение пишет, что не может связаться с Google Диском.** Оно продолжает
работать с тем, что уже скачано, но не отправляет изменения — чтобы не затереть
чужую работу. Проверьте интернет и перезапустите.

**Документы, добавленные на другом компьютере, не видны.** Обновите страницу:
приложение проверяет Диск не чаще раза в 15 секунд.
